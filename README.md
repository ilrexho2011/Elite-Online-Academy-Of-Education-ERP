## SAP / Integration Perspective

A particularly important elemenet of the package is the direction toward SAP-related integration. 
The package is intended either as a proof-of-concept or as an evolving hybrid solution where the education platform is connected with enterprise integration patterns.

•	SAP UI5 / Fiori can serve as an enterprise-grade frontend or launch point for selected workflows.
•	SAP Integration Suite can orchestrate data exchange, transformation, and process automation using iFlows.
•	API Management can secure, version, and expose REST services.
•	Cloud Connector can bridge cloud and on-premise resources such as SQL Server or internal systems.
•	OData / S/4HANA connectivity can support ERP-aligned CRUD or master-data synchronization scenarios.


- iFlow creation in SAP Cloud Integration to adjust and transmit the exams data
- Create a web API in SAP Fiori (UI5) to start the process
- Build API proxy for REST API from API provider, 
- Create and publish a product, add Policy, generate and use API-Key
- Using Cloud Connector to manipulate the SQL database
- CRUD operations through Odata adapter in SAP S/4Hana database
- Frontend development with PHP, JS, HTML5 & CSS
- Server backend development with PHP, Javascript)
- Use of XML, JSON and Ajax data languages – data parsing and conversion
